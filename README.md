# ①課題名
ManiArc mini01（熱量アーカイブアプリ）

## ②課題内容（どんな作品か）
- 推し活・スポーツ・ゲームなど、自分が「何に、いつから、どのような形で夢中になっているか」を宣言できるアプリです。
- 登録した内容をCSVに保存し、「熱量パスポート」として一覧表示します。継続年数の集計、ジャンル別の絞り込み、登録内容の編集もできます。

## ③アプリのデプロイURL
未デプロイ

## ④アプリのログイン用IDまたはPassword（ある場合）
- ID: なし
- PW: なし

## ⑤工夫した点・こだわった点
- 単なる入力一覧ではなく、一つひとつの記録を「熱量パスポート」として見せるデザインにしました。
- 選択したジャンルに応じて「愛の形」の説明文が変わるようにし、入力内容をイメージしやすくしました。
- CSVへの書き込み・読み込み・更新時にファイルロックを行い、同時アクセスによるデータ破損を防ぐようにしました。
- サーバー側でも必須項目、文字数、年の範囲、選択肢を検証し、表示時にはHTMLエスケープを行っています。
- アーカイブ全体の継続年数を集計し、ジャンル別にパスポートを絞り込めるようにしました。

## ⑥難しかった点・次回トライしたいこと（又は機能）
- CSV内の特定レコードを安全に編集するため、レコードを識別するIDの生成とファイル全体の再書き込み処理に苦労しました。
- ログイン機能を追加し、ユーザーごとに自分のアーカイブだけを閲覧できるようにしたいです。
- 画像登録、検索、並び替え、削除、継続年数の自動更新なども追加したいです。

## 主なファイル

- `input.php`: 熱量宣言フォーム
- `write.php`: 入力検証とCSV保存
- `read.php`: アーカイブ一覧・集計・ジャンル絞り込み
- `edit.php`: 登録内容の編集
- `functions.php`: 共通定数・共通関数
- `style.css`: 画面デザイン
